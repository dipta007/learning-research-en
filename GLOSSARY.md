## Hedges

Keep each hedge at its own strength, and keep the two apart. Verification caught them collapsing into each other twice.

This table is the main defence against the defect that dominates this repository. Across 17 verification rounds it has been the same thing again and again: he writes hedged and emphatic, and the English comes out neutral and absolute. Each dropped particle looks trivial on its own. Together they rewrite his voice. Read this table before translating, and check the finished text against it afterwards.

| Chinese | English |
|---|---|
| 推荐 | it is recommended that |
| 建议 | it is suggested that |
| 可能 | may |
| 比较 | fairly (a relative degree, not "the more X of two") |
| 难以 | it is hard to (not "cannot") |
| 一定的 | a certain amount of |
| 有所 | of some (有所帮助 = "of some help", not "helps") |
| 总结 | summarize (not "collect", not "lay out") |
| 尽量 | as far as possible; before an adjective, "as ... as possible" (尽量很酷 = "as cool as possible") |
| 某个 / 某一 | a certain (one particular one, not the bare numeral "one") |
| 一些 | some (a subset, so keep the word; "the basic concepts" reads as the full set, 一些基础的概念 does not) |
| 具体 | concretely, or "the concrete ..." |
| 具体请看 | for the details, please see |
| 适用于 | applies to (not "reflects") |
| 不一定 | not necessarily (not "not always", which adds a frequency sense) |
| 能够 | can (a capability, so do not drop it) |
| 不要求 | not required (not "not the goal") |
| 定制 | tailor |
| 需要 | need to (keep it; 还需要看 is "you also need to watch", not "also watch"). Before a noun, 需要的能力 is "the abilities needed", not "the abilities it takes" |
| 老师 | Prof. (see the note below) |
| 教授 | Prof. |
| 很 | very. **The single most-dropped word in this repository.** 很挣扎, 很烦, 很散, 很怪, 很没意思, 很有意思, 很大, 很快, 很熟练, 很高级, 很懂, 很straightforward all lost it. He writes emphatically; without 很 he reads flat |
| 有些 | some |
| 极强 | extremely strong (one rendering, not "very strong" a clause later) |
| 才 / 才能 | only then. A necessary condition, not a loose cause. "so that readers remember them" loses it; "and only then do readers remember them" keeps it |
| 才有可能 | only then is it possible |
| 应该 | should, for obligation. **But for a confident inference it is "must have"**: 应该把技术栈都摸了遍 is "must have worked through", not the weaker "seems to have" |
| 能 / 可以 | can. Dropped in a dozen places, turning his abilities into flat certainties |
| 只能 | can only |
| 没什么 | hardly any (not "fine") |
| 各种 | all sorts of (not "every", which claims exhaustiveness) |
| 完全 | completely (one rendering, not "fully" then "purely") |
| 直接 | directly |
| 始终 | always |
| 等 / 等等 | and so on. Marks the list as open; dropping it makes the list read complete |

## 老师 becomes "Prof."

He writes 老师 for Prof. Xiaowei Zhou, Prof. Lingqi Yan, and Prof. Libin Liu, and 教授 for Prof. Andrej Karpathy. 老师 is the ordinary respectful way to address anyone who teaches you. It claims no rank. English has no equivalent, so the choice is between asserting a rank and dropping the respect marker, and both lose something.

The settled choice is "Prof." for both words. It reads naturally, it is applied to every 老师 in the repository, and it is true of all four people. Verification flags it as an addition each time, so it is written down here as a decision.

This is not the same as the mistake recorded in `.claude/CLAUDE.md`, where "Prof." was attached to a name the source gave no honorific at all. Translating an honorific is fine. Inventing one is not.

## One deliberate loss: 学长 / 学姐

He writes 学长/学姐, a pair meaning an older male schoolmate and an older female schoolmate. English has no matching pair. "Senior student" is the settled rendering everywhere, and the gender marking is dropped on purpose. Verification flags this as a dropped alternative each time it runs, so it is written down here: it is a decision, not an oversight. Spelling it out in English ("a senior male or female student") would be clumsy in every one of the four places it appears, and would put weight on gender that his sentences do not.
