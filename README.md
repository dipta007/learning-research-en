# learning_research, in English and Bengali

An English and Bengali translation of Prof. Peng Sida's open research notes: https://github.com/pengsida/learning_research

The original notes are written in Chinese. They are widely read (over 14,000 stars) and full of practical advice on how to actually do research: how to start, how to get better, how to write. This repository makes that advice readable for people who do not read Chinese.

**Read in another language:** [বাংলা](./README_bn.md)

## Status

All four files are translated. Every one is a first draft and still needs a review pass: a Chinese reader for accuracy, a native Bengali speaker for the Bengali.
